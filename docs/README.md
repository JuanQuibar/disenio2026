# Documentación y capturas

La documentación **vigente** está en la raíz del repositorio. Para retomar el
proyecto, leer [PROGRESS.md](../PROGRESS.md),
[PROJECT_CONTEXT.md](../PROJECT_CONTEXT.md) y [README.md](../README.md), en ese
orden. Para trabajar en la interfaz, consultar también [DESIGN.md](../DESIGN.md).

Documentos de consulta según la tarea:

- [CATALOGO_FORMATOS_PORTADA.md](../CATALOGO_FORMATOS_PORTADA.md): formatos y
  acuerdos editoriales de la home aprobada.
- [PORTADA_SECCION.md](../PORTADA_SECCION.md): portada de sección genérica
  aprobada y sus capturas.
- [AGENTS.md](../AGENTS.md): reglas de trabajo para agentes.
- [BROWSER_TESTING.md](../BROWSER_TESTING.md): guía del navegador compartido.

En esta carpeta, `formatos/` y `portada-seccion/` contienen **capturas visuales**
enlazadas desde las fichas de la raíz. Las versiones anteriores de las guías se
conservan en el [archivo histórico](../archivo/2026-10-26/README.md); no
describen el estado vigente del proyecto.
